Pertanyaan umum

Apa itu Zone ID?

Zone ID adalah angka server akun Mobile Legends. Di profil game, angka ini tampil dalam tanda kurung di samping User ID, contoh: 12345678 (1234). User ID = 12345678, Zone ID = 1234. Game lain tidak memakai Zone ID.

Di mana melihat ID akun?

Mobile Legends: buka profil (ketuk foto di pojok kiri atas). Free Fire: buka profil, lihat Player ID. Roblox: pakai username (bukan display name) yang ada di halaman profil.

Berapa lama diamond masuk?

Setelah bukti transfer dikirim dan dicek admin, pesanan diproses. Biasanya hanya beberapa menit.

Salah ID, bagaimana?

Periksa ID sebelum membayar. Pesanan dengan ID salah tidak bisa dibatalkan setelah diproses. Jika ragu, tanyakan ke admin dulu.
